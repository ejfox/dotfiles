# OBS

OBS Studio config for the iMac Pro streaming rig. Symlinked live, so edits made in the
OBS UI land here and show up in `git diff`.

```
~/Library/Application Support/obs-studio/
├── basic                     → ~/.dotfiles/obs/basic
└── plugin_config/obs-midi-mg → ~/.dotfiles/obs/plugin_config/obs-midi-mg
```

`sync-dotfiles.sh` recreates the links. They are **directory** links on purpose: OBS saves
by writing a temp file and renaming it over the original, which would silently replace a
per-file symlink with a plain file.

## What's here

| Path | What |
|---|---|
| `basic/scenes/EJ_Live_2026.json` | The scene collection: scenes, sources, filters, hotkeys, Advanced Scene Switcher settings |
| `basic/profiles/Untitled/basic.ini` | Output/encoder/video settings |
| `plugin_config/obs-midi-mg/obs-midi-mg-config.json` | Midi Fighter 3D → OBS bindings (generated by `~/code/stream-overlays/midifighter/wire-obs.py`) |

The overlays themselves (browser sources, shaders, the `:7788` stats server) live in
their own repo: `~/code/stream-overlays`.

## Kept out of git (this repo is public)

- `basic/profiles/*/service.json`: the **stream key**. Gitignored before it exists.
- `plugin_config/obs-websocket/config.json`: websocket password. Never linked.
- `user.ini` / `global.ini`: window-geometry churn. Not linked; the settings that matter are noted below.
- `*.bak*`, and the default `Untitled` collection.
- The iPhone's hardware UDID (`setting_device_uuid`) is scrubbed on commit by the
  `obs-redact` git clean filter (`.gitattributes`). The local file keeps the real value,
  and only the committed copy says `REDACTED-IPHONE-UDID`. On a fresh machine, re-pick the
  iPhone in the iOS Camera source.

## Settings that matter

- **Scene hotkeys are ⌃⌥1–9.** They used to be bare `1`–`9`, and with
  `HotkeyFocusType=NeverDisableHotkeys` (in `user.ini`) typing any digit in any app switched scenes.
- **Midi Fighter bindings match channel 3 only** (the pads). obs-midi-mg channels are 1-based.

## Editing by hand

Quit OBS first, since it rewrites these files on exit. `osascript -e 'tell application "OBS" to quit'`
returns error -128 "User canceled" but does quit; confirm with `pgrep -x OBS`.
