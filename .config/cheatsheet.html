Folds
folds follow real code structure (treesitter / LSP, not indent guesses). foldlevel is a depth dial: 0 = everything shut, 99 = everything open. LazyVim starts at 99, so you close what you want rather than dig out.
this fold — at the cursor
zatoggle (the everyday key)
zo / zcopen / close, just this one
zA / zO / zCsame, but recursive (nested)
zKpeek inside without opening (ufo)
zvopen just enough to see cursor
whole file — slide the level dial
zM / zRslam shut / fling open
zm / zrone level tighter / looser
zifolding on/off entirely
move between folds
zj / zknext / prev fold
[z / ]zstart / end of current fold
mnemonics: m = more folding, r = reduce it; caps go all the way (Max / Reset). z = folded paper.
strategy · collapse to navigate zM shut everything → read the file as an outline of names zj zk jump to the block, za cracks just that one zR fling it all open again — zoom-out / zoom-in for code zm zr peel structure one layer at a time when all-or-nothing is too blunt zK glance inside a fold mid-scroll without losing your place on a closed fold, yy / dd hit every line in it — grab or move a whole block in one keystroke
